# SnapLight Website

https://alima3s.github.io/Snap-Light/

Standalone static site for SnapLight.

## Files
- `index.html`
- `styles.css`
- `SnapShotLogo.png`


## Publish
1. Move this folder into a separate public repository.
2. Update the download link in `index.html` (`https://github.com/your-username/snaplight/releases/latest`).
3. Update the PayPal link in `index.html` (`https://www.paypal.com/paypalme/your-name`).
4. Replace files in `screenshots/` with your real app screenshots (keep the same filenames or update `index.html`).
5. Deploy with GitHub Pages.
